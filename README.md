# 🌤️ WeatherApp - Angular

Aplikacja pogodowa zbudowana w oparciu o framework **Angular**. Projekt pozwala na sprawdzanie aktualnej pogody oraz prognozy dla dowolnego miasta na świecie, korzystając z zewnętrznego API.

## ✨ Funkcje
- **Wyszukiwanie miast:** Dynamiczne wyszukiwanie pogody dla dowolnej lokalizacji.
- **Aktualne dane:** Temperatura, wilgotność, ciśnienie oraz prędkość wiatru.
- **Responsywny design:** Aplikacja działa płynnie na komputerach, tabletach i smartfonach.

## 🚀 Technologie
- **Frontend:** Angular (wersja [wpisz swoją, np. 17/18])
- **Język:** TypeScript
- **Stylizacja:** Tailwind
- **API:** [OpenWeatherMap API](https://openweathermap.org/)
